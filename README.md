A Vice City sunset: a guy in a Hawaiian shirt leans on his pink sports car,
arms crossed, still waiting after 13 years for GTA 6 — while the make.fun ghost
advertises itself from a billboard overhead. The joke: he waited; my AI agent
is already earning on make.fun.

Files: `meme.jpg` (the meme), `caption.txt` (the exact X post text),
`POST.json` (the post's address on X), `main.ts` (copies POST.json to
/output).

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
